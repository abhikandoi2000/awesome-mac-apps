# awesome-mac-apps
macOS apps along with what sets each apart

## Terminal

| Name | Short brief |
| --- | --- |
| [iterm2](https://iterm2.com/) | modern terminal for macOS, hotkey window, configurable, triggers, instant replay |
| [ghostty](https://ghostty.org/) | speed, features, or native UIs. Ghostty provides all three |
| [warp](https://www.warp.dev/terminal) | commercial, requires-login, features: warp features for remote sessions, generating commands, dispatch agents, best if you pay, most powerful |
| [rex](https://www.superlogical.com/rex/docs/installation) | an incredible & beautiful multiplexer. A work-in-progress |


## Agentic Coding (CLI focused)

| Name | Short brief |
| --- | --- |
| [claude code](https://www.anthropic.com/claude-code) | commercial closed-source agent, best agentic coding software out there, sub-agents, tool-calling, intelligent |
| [codex cli](https://github.com/openai/codex) | commercial open-source agent, good alternative to claude code |
| [warp](https://www.warp.dev/agents) | commercial, requires-login, features: terminal integrated, agent mode, dispatch agents, best if you pay |

## Coding Agents (GUI focused)
| Name | Short brief |
| --- | --- |
| [claude](https://claude.com/download) | the best agentic coding software out there, remote-control, cloud sessions, curated plugins |
| [chatgpt](https://chatgpt.com/download/) | commercial open-source agent, good alternative to claude code, token-efficient coding agents |
| [amp](https://ampcode.com/app) | multi-player collab dev environment and coding agent, orb/cloud-focused, thoughtful & superb design; web, android & ios apps |
| [delta](https://delta.dev/) | multi-player collab env. for humans to code with agents, early stages yet brilliant |

> Personally I'd bet on Amp and Delta in addition to Claude. There will be several winners.
